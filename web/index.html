Input count matrix

CSV columns: gene_id,length_bp,count. Additional columns after length_bp are treated as separate samples. Use counts of reads for single-end data or fragments for paired-end data.

For a filtered count table, supply the full library read/fragment count to compute FPKM against the original sample. TPM is normalized across supplied features.

Normalization definitions

TPM

1,000,000 × (countᵢ / lengthᵢ) / Σ(countⱼ / lengthⱼ)

TPM sums to one million across input features for each sample.

FPKM

1,000,000,000 × countᵢ / (lengthᵢ × library size)

Gene lengths are in base pairs. Counts and library totals must use consistent read/fragment units.

FPKM and RPKM have the same numerical formula, but the denominator represents fragments for paired-end FPKM and reads for single-end RPKM. Values depend on the supplied feature lengths and the definition of mapped-library size; TPM/FPKM are not substitutes for statistical count-based differential expression analysis.
